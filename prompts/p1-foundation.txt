# Bold Coat Painters Website - Phase 1: Foundation Setup

You are setting up the foundation for boldcoatpainters.com, a complete migration from WordPress to a modern Astro site for Bold Coat Painters, a high-end residential painting company in Chicago. This is Phase 1 of 9, focused EXCLUSIVELY on FOUNDATION. Do not build page sections, content, or full forms yet. Those are later phases.

Always use the latest stable version of every dependency. Do not pin to specific versions you remember; check for the latest stable release at install time and use that. If you are unsure what the latest version is, use `npm view <package> version` or use `latest` tag in install commands.

================================================================================
PROJECT CONTEXT
================================================================================

- Company: Bold Coat Painters (Bold Coat LLC), Chicago IL, residential painting, year 2
- Owner: Mohmed
- Target audience: high-end homeowners in North Shore suburbs (Winnetka, Glencoe, Lake Forest, Highland Park, Hinsdale, Wilmette, Kenilworth) and affluent Chicago neighborhoods (Lincoln Park, Gold Coast, Lakeview), $3,000+ avg ticket
- Services: Interior Painting, Exterior Painting, Cabinet Painting/Refinishing
- Eventual full site replacing WordPress at boldcoatpainters.com
- Three landing pages for paid Google Ads: /interior-quote/, /exterior-quote/, /cabinet-quote/
- SEO-focused service pages: /services/interior-painting/, /services/exterior-painting/, /services/cabinet-painting/
- Area pages: /areas/[region]/[city]/ (Phase 5)
- Blog at /blog/ (Phase 6)
- Site must rank organically. Indexable, real E-E-A-T signals, named author (the owner)

================================================================================
TECH STACK (use exactly these, always latest stable)
================================================================================

- Framework: Astro (latest stable)
- Styling: Tailwind CSS (latest) via official Astro integration
- Language: TypeScript (latest stable), strict mode everywhere
- Form library: React (via @astrojs/react) + React Hook Form + Zod (form built in Phase 2)
- Validation: Zod (shared client + server schemas)
- Hosting: Cloudflare Pages static + Cloudflare Pages Functions
- Email: Zoho Mail SMTP via Nodemailer (server-side, in Pages Function)
- CRM: DripJobs webhook (POST JSON)
- Spam protection: Cloudflare Turnstile
- Analytics: Google Tag Manager (single container drives GA4, Google Ads, Microsoft Clarity)
- Linting: ESLint + Prettier
- Node: pin via .nvmrc to current LTS

================================================================================
ARCHITECTURAL PRINCIPLES (NON-NEGOTIABLE)
================================================================================

1. Zero hardcoded values outside config files. Every phone number, color, URL, business name reference traces to site.ts, theme.ts, routes.ts, or env vars.
2. Type safety end-to-end. TypeScript strict. Zod for runtime validation at all boundaries.
3. Fail-fast. Missing required env vars break the build, not production.
4. Future-ready, not future-built. Content Collections directories and schemas exist; no content yet. Routing config supports blog/areas; pages don't exist yet.
5. Component composition. UI primitives in components/ui/, layouts in components/layout/, sections will live in components/sections/ (Phase 2), nav in components/nav/.
6. Server-only code stays server-only. SMTP credentials and webhook URLs ONLY in functions/. Never imported into src/.
7. Accessibility from day 1. Semantic HTML, proper heading hierarchy, focus states, aria labels, color contrast 4.5:1+ for body text.
8. SEO from day 1. Schema.org JSON-LD on every page. Indexable by default. Canonical URLs auto-built. AI crawlers explicitly allowed.
